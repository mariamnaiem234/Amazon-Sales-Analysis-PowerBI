# Data Dictionary

| Column | Description |
|---|---|
| Order ID | Unique identifier for each order |
| Date | Order date |
| Status | Current order status |
| Fulfilment | Order fulfilment method |
| Qty | Number of units ordered |
| Amount | Order sales amount |
| Category | Product category |
| Size | Product size |
| Style | Product style |
| B2B | Indicates whether the order is B2B |
| Ship City | Shipping destination city |
| Ship State | Shipping destination state |
| Ship Postal Code | Shipping destination postal code |
| Ship Service Level | Shipping service selected by the customer |
| Courier Status | Shipping/courier status |
